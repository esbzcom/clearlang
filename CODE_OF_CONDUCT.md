# Code of Conduct

## Our Standards

We are committed to a respectful, inclusive, and constructive community.

Examples of expected behavior:

- Be respectful and professional.
- Assume good intent and ask clarifying questions.
- Give actionable technical feedback.
- Focus on the work, not the person.

Examples of unacceptable behavior:

- Harassment, discrimination, or abusive language.
- Personal attacks or trolling.
- Publishing private information without consent.
- Disruptive or intentionally hostile conduct.

## Scope

This Code of Conduct applies in project spaces, including issues, pull requests, discussions, and other community channels.

It also applies to code review conduct on production-path pull requests targeting `main`.

## Enforcement

Project maintainers are responsible for interpreting and enforcing this policy. They may remove content or restrict participation for behavior that violates this code.

Maintainers may pause or close PRs when conduct in review threads violates this policy.

## Reporting

For conduct concerns, open a private maintainer contact through GitHub (private discussion or security advisory) rather than a public thread when appropriate.
