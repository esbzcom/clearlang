# Phase 25.0.10 - Cross-Platform Proof Parity Gate

## Status
Design lock + implementation note for `25.0.10` in `docs/TODO.md`.

## Goal
Require release-target parity so Linux/Windows/macOS produce equivalent proof outcomes and deterministic assurance status for the milestone_3 parity fixture.

## Policy
1. CI executes a cross-platform parity matrix on:
   - `linux`
   - `windows`
   - `macos`
2. Each platform emits a deterministic proof parity artifact (`schema_version=1`) generated by:
   - `cargo test -p clg-cli --test milestone3_proof_parity`
3. A compare job fails closed unless parity artifacts are byte-identical across all three platforms.
4. Milestone_3 tag gate requires parity-compare success before publish gate execution.

## Enforcement Wiring
- New integration test:
  - `crates/cli/tests/milestone3_proof_parity.rs`
- CI jobs:
  - `milestone3-proof-parity` (matrix)
  - `milestone3-proof-parity-compare` (artifact equality check)
- Milestone_3 release-train job requires:
  - `checks`
  - `milestone3-proof-parity-compare`

## Exit Criteria for 25.0.10
1. Linux/Windows/macOS parity artifacts are emitted in CI for the parity fixture.
2. Compare job enforces byte equality of parity outputs.
3. Release-train gate depends on parity-compare.
4. TODO marks `25.0.10` complete with design + CI + test references.
